Searching stories

Send a GET request to /api/v1/search with a query parameter. Results come back in hits, newest first when you use /api/v1/search_by_date. Each page holds up to 1,000 hits, and nbHits is the total match count.

Filters

Use tags for the item type (story, comment, poll) and numericFilters for points and dates, for example points>=50,created_at_i>1700000000. Join several filters with commas.
